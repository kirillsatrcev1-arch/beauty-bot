# 🎀 BEAUTY STUDIO BOT

Telegram-бот для мастера маникюра и педикюра. Клиентки записываются в нём сами. Внутри есть Mini App в стиле luxury / clean girl: молочный, пудровый, шампань, золото, шрифты Cormorant Garamond и Manrope.

Стек: **Python 3.11+, aiogram 3, SQLite (aiosqlite), FSM, aiohttp (Mini App + API)**.

---

## Что умеет

**Для клиенток (в чате)**
- Приветствие с фото и меню: запись, прайс, портфолио, «Обо мне», адрес, связь с мастером, мои записи, отзывы, избранное.
- **Обязательная подписка на канал перед записью.** Бот сам проверяет её на сервере через `getChatMember`. Кнопки: «🤍 Подписаться на канал» и «✨ Я подписалась».
- **Запись по шагам (FSM):**
  1. категория;
  2. процедура;
  3. календарь со свободными и занятыми днями;
  4. только реально свободное время;
  5. имя и телефон (кнопка «Отправить номер», сохраняются для следующих записей) и комментарий;
  6. проверка;
  7. карточка «Твоя запись успешно создана! ♡» с кнопками «Перенести» и «Отменить».
- Прайс по категориям. У каждой услуги карточка: фото, описание, цена, длительность, «Записаться», «♡ В избранное», листание ‹ ›.
- Портфолио по разделам: Нюдовый, Французский, Красный, Дизайн, Наращивание, Педикюр, До/После. Листание ◀ ▶, «🔍 Оригинал» (присылает файл в полном качестве), галерея с зумом в Mini App.
- «Мои записи»:
  - перенос и отмена (не позже чем за N часов);
  - история визитов;
  - «🔁 Повторить» и «Как в прошлый раз».
- Отзывы со звёздами (после модерации мастером), избранные услуги, «✍️ Написать мастеру прямо здесь».

**Уведомления**
- **Клиентке:**
  - запись создана;
  - мастер подтвердил;
  - напоминание за 24 ч (с кнопкой «✅ Буду обязательно!») и за 2 ч;
  - время изменено;
  - запись отменена;
  - просьба оставить отзыв после визита.
- **Мастеру:**
  - новая заявка (с кнопками ✅ / ❌ / 🔁);
  - клиентка подтвердила визит;
  - отмена;
  - перенос.

**Админ-панель мастера** (`/admin` или кнопка «👑 Админ-панель», видна только ADMIN_IDS)
- 📋 **Записи:** ждут подтверждения, сегодня, завтра, 7 дней, по дате, прошедшие. Действия: подтвердить, отменить (можно с причиной), перенести, «визит состоялся», написать клиентке.
- 🗓 **График:**
  - рабочие часы и рабочие дни;
  - закрыть или открыть дату;
  - особые часы на дату;
  - дополнительные окошки;
  - шаг сетки;
  - на сколько дней вперёд открыта запись;
  - минимум времени до записи;
  - срок отмены.
- 💅 **Услуги:** добавить, переименовать, описание, цена (в том числе «от»), длительность, фото, скрыть, удалить, обложки категорий.
- 🦢 **Портфолио:** загрузка фото и альбомов. Если отправлять **файлом**, сохраняется оригинал. Просмотр и удаление.
- 🖼 **Тексты и фото:** «Обо мне», имя, адрес, «как пройти», ссылка на карту, контакты, фото любого раздела вместо стандартной обложки.
- 📣 **Канал:** ID и ссылка, вкл/выкл обязательной подписки, проверка, что бот — админ канала.
- 👥 **Клиентская база:** поиск по имени и телефону; карточка клиентки с визитами, суммой, отменами, избранным; личное сообщение.
- 📣 **Рассылка:** текст, фото, видео — всем или только клиенткам с визитами. Есть превью, учёт лимитов Telegram и отчёт.
- 📊 **Статистика:**
  - сегодня, 7 и 30 дней: визиты, выручка, средний чек, заявки, отмены;
  - топ услуг;
  - подписчики канала;
  - постоянные клиентки.
- ⭐ **Модерация отзывов.** ⚙️ Автоподтверждение записей, напоминания вкл/выкл.

**Mini App** (кнопка меню «Запись ♡» и «✨ Открыть beauty-приложение»)
- Красивая витрина, прайс с карточками и избранным.
- Запись с календарём, перенос и отмена.
- Галерея портфолио с **свайпом, pinch-zoom и двойным тапом**.
- «Мои записи» и кабинет мастера: записи по дням, подтверждение.

**Надёжность**
- Всё хранится в SQLite. Каждое действие пишется в журнал `events`.
- Состояние FSM тоже в БД, поэтому незаконченная запись переживает перезапуск.
- **Двойная запись невозможна:** бронирование идёт в транзакции `BEGIN IMMEDIATE` с повторной проверкой пересечений внутри неё. Дополнительно стоит уникальный индекс на время начала активных записей. Тест «30 клиенток одновременно жмут одно время» проходит: запись получает ровно одна.
- Mini App API проверяет подпись Telegram `initData` (HMAC-SHA256). Фото отдаются только те, что известны боту.

## Быстрый старт

### 1. Подготовка в Telegram
1. В [@BotFather](https://t.me/BotFather) выполните `/newbot` и получите **токен**.
2. Узнайте свой Telegram ID, например у [@userinfobot](https://t.me/userinfobot). Это будет `ADMIN_IDS`.
3. Канал: создайте его (или возьмите существующий) и **добавьте бота администратором канала**. Права можно минимальные. Без этого Telegram не даст проверить подписку.

### 2. Запуск на компьютере или сервере
```bash
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env               # впишите BOT_TOKEN и ADMIN_IDS
python -m app
```
Бот запустится, создаст `data/beauty.db` с примерами услуг и нарисует обложки разделов в `data/covers`.

### 3. Первая настройка (в боте, команда `/admin`)
1. **⚙️ Настройки и канал → ✏️ ID канала**: `@ваш_канал` (или `-100…` для приватного) и ссылка-приглашение. Бот сразу покажет, работает ли проверка.
2. **🖼 Тексты и фото**: адрес, «как пройти», ссылка на Яндекс/Google Карты, текст «Обо мне», ваш @username и телефон. В «Фото разделов» загрузите своё фото для «Обо мне» и приветствия.
3. **💅 Услуги и цены**: поправьте цены и длительности, добавьте фото к услугам.
4. **🗓 График**: часы, рабочие дни, выходные даты.
5. **🦢 Портфолио**: загрузите работы в разделы. Лучше файлами: тогда клиентки увидят оригинал.

### 4. Mini App (нужен HTTPS)
Mini App открывается только по **https**. Бот поднимает веб-сервер на порту `PORT` (по умолчанию 8080).
- **Сервер с доменом.** Поставьте перед ботом Caddy или nginx с сертификатом и укажите `WEBAPP_URL=https://ваш-домен`. Пример для Caddy:
  ```
  beauty.example.ru {
      reverse_proxy 127.0.0.1:8080
  }
  ```
- **Хостинги Railway, Render, Amvera.** Они сами дают HTTPS-адрес: укажите его в `WEBAPP_URL`. Хранилище `/data` сделайте постоянным (volume) и задайте `DATA_DIR=/data`.
- **Быстрая проверка с компьютера:** `cloudflared tunnel --url http://localhost:8080`. Полученный `https://….trycloudflare.com` впишите в `WEBAPP_URL` и перезапустите бота.

При заданном `WEBAPP_URL` бот сам ставит кнопку меню «Запись ♡» и добавляет кнопку приложения в главное меню. Без `WEBAPP_URL` всё работает в чате, просто без Mini App.

### Docker
```bash
cp .env.example .env    # заполните
docker compose up -d --build
```
База и фото лежат в `./data`. **Бэкап — это просто копия папки `data`.**

## Структура проекта
```
app/
  __main__.py        запуск: бот (long polling) + веб-сервер Mini App + планировщик
  config.py          настройки из .env
  db.py              схема SQLite, стартовые данные, репозиторий, журнал действий
  scheduling.py      рабочие окна, свободные слоты, атомарная запись и перенос
  logic.py           создание/подтверждение/отмена/перенос + уведомления обеим сторонам
  notifications.py   напоминания 24 ч / 2 ч, завершение визитов, просьба об отзыве
  subscription.py    проверка подписки на канал (getChatMember)
  covers.py          генерация обложек разделов (Pillow)
  ui.py              «экраны»: одно сообщение-карточка редактируется на месте
  keyboards.py, texts.py, middlewares.py, fsm_storage.py
  handlers/          start, booking, catalog (прайс/портфолио/избранное), my, reviews, admin
  web/               server.py (API + прокси фото), auth.py (initData), static/index.html (Mini App)
tests/               сценарии бота через фейковый Telegram API, гонки, API Mini App
scripts/preview_webapp.py   локальный предпросмотр Mini App на демо-данных
```

## Тесты
```bash
pip install -r requirements-dev.txt
pytest
```
Что проверяют тесты:
- весь путь клиентки: подписка → запись → подтверждение мастером → перенос → отмена;
- сохранённые контакты и повтор записи;
- админ-панель и закрытый доступ к ней;
- напоминания и отзывы;
- портфолио, прайс и избранное;
- 30 одновременных записей на одно время, а также гонку двух отдельных соединений с БД;
- API Mini App: подпись, обязательная подписка, гонку, доступ.

## Полезно знать
- Стартовые услуги и цены — это пример. Меняйте их в админке.
- Статусы записи: 🤍 ждёт подтверждения → 💗 подтверждена → ✨ визит состоялся (ставится автоматически после окончания) / ✖️ отменена. Неподтверждённые прошедшие заявки помечаются как «не подтверждена».
- Нужно без ручного подтверждения? Включите **⚙️ Автоподтверждение**.
- Если бот не админ канала, проверка подписки не блокирует клиенток: запись продолжает работать. В лог пишется ошибка, а в админке видно предупреждение.
