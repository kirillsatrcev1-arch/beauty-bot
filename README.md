# 💅 Nail Studio — Telegram Mini App для записи на маникюр

Премиальное приложение внутри Telegram для мастера маникюра (или студии с несколькими мастерами). Клиентки записываются сами. Мастер управляет записями, расписанием, услугами, фото и рассылками из веб-админки.

| Часть | Технологии |
|---|---|
| Mini App (клиенты + админ-панель) | React 18, TypeScript, Vite, Tailwind CSS, Framer Motion, Lucide Icons |
| Сервер, API, бот | Python 3.11+, aiohttp, aiogram 3 (Telegram Bot API) |
| База данных | SQLite (WAL); фото хранятся на диске в `data/uploads` |
| Безопасность | проверка подписи Telegram `initData` на сервере, права админа — только на сервере |

> **Почему не Supabase.** В проекте уже был рабочий бэкенд на Python + SQLite с проверенной логикой: защита от двойной записи, уведомления, напоминания, админка в чате. Его расширили, а не переписали. Внешних аккаунтов и ключей не нужно, всё в одном контейнере. API отделён от интерфейса (`webapp/src/services/api.ts`), поэтому при росте студии базу можно перенести на PostgreSQL или Supabase, не трогая фронтенд.

## Что умеет

**Клиентка (Mini App)**
- **Главная:**
  - приветствие с именем и аватаром из Telegram;
  - большой фото-баннер «Твоя красота начинается с деталей»;
  - ближайшее свободное окно;
  - услуги, популярные дизайны, последние работы;
  - «Почему выбирают нас», мастера, отзывы, контакты.
- **Услуги:** поиск, фильтры по категориям, карточки с фото, описанием, ценой и длительностью, кнопка «Выбрать», избранное.
- **Запись в 6 шагов:**
  1. услуга;
  2. мастер (или «Любой мастер»);
  3. дата в календаре со свободными и занятыми днями;
  4. свободное время (утро / день / вечер);
  5. контакты;
  6. подтверждение.

  Затем экран успеха с анимацией и кнопками **«Добавить в календарь»** (.ics) и «Мои записи».
- **Галерея:** разделы, сетка «кирпичиком», полноэкранный просмотр с плавным увеличением из сетки, свайп, двойной тап для зума.
- **Профиль:**
  - ближайшая запись крупной карточкой: перенос, отмена, «в календарь»;
  - остальные записи и их статусы;
  - история визитов с «Повторить»;
  - мастер, контакты, правила отмены.
- **Оформление:** светлая и тёмная тема, микроанимации, скелетоны загрузки, учёт `prefers-reduced-motion`, системная кнопка «Назад» Telegram, тактильная отдача.
- **Подписка на канал:** обязательна перед записью, проверяется на сервере через `getChatMember`.

**Мастер (веб-админка `/admin`)**
- **Обзор:** записи сегодня и за неделю, новые клиенты, выручка, ближайшие записи, графики по месяцам и за 14 дней, популярные услуги.
- **Записи:** поиск по имени, телефону и услуге; фильтры по дате, мастеру и статусу. Подтверждение, отмена с причиной, перенос со свободными слотами, смена статуса, ручная запись.
- **Календарь:**
  - вид «день»: колонки мастеров, рабочие окна, перерывы, блокировки, записи; нажатие на свободное время создаёт запись;
  - виды «неделя» и «месяц».
- **Услуги:** добавить, изменить, удалить, включить/выключить, цена (в том числе «от»), длительность, фото.
- **Мастера:** имя, фото, описание, список услуг, индивидуальный график, перерыв, отключение.
- **Расписание:**
  - график студии и шаг сетки;
  - отпуска;
  - выходные и особые часы (для студии или мастера);
  - блокировка окон;
  - дополнительные окна.
- **Клиенты:** список с Telegram ID, визитами и суммой; карточка с историей и контактами.
- **Галерея:** загрузка нескольких фото сразу, подписи, перенос между разделами, удаление.
- **Настройки:**
  - название, логотип, адрес, контакты, соцсети, фото на главной и фото мастера;
  - правила отмены, канал и обязательная подписка;
  - уведомления, автоподтверждение.

**Уведомления (Telegram Bot API)**
- Клиентке: запись создана, подтверждена, напоминания за 24 ч и за 2 ч, время изменено, запись отменена, просьба об отзыве.
- Мастеру: новая заявка, отмена, перенос, клиентка подтвердила визит, **новая клиентка**.

**Надёжность**
- Свободное время считается на сервере. Учитываются:
  - график мастера, перерыв, отпуск, выходные, блокировки, дополнительные окна;
  - длительность услуги;
  - уже существующие записи;
  - минимальное время до записи.
- **Двойная запись невозможна:** бронь создаётся в транзакции `BEGIN IMMEDIATE` с повторной проверкой. Дополнительно стоит уникальный индекс `(master_id, start)` для активных записей. Тесты проверяют это на 30 одновременных запросах и на двух мастерах.
- Каждое действие пишется в журнал `events`. Состояние диалогов бота хранится в БД.

## Структура
```
app/                    Python: бот, API, логика
  __main__.py           запуск: бот + веб-сервер + планировщик напоминаний
  db.py                 схема SQLite, миграции, начальные данные
  scheduling.py         расписание мастеров, свободные слоты, атомарная запись и перенос
  logic.py              запись/подтверждение/отмена/перенос + уведомления
  notifications.py      напоминания 24 ч / 2 ч, завершение визитов, отзывы
  media.py              загрузка и хранение фото
  web/server.py         публичный API Mini App, файлы, .ics
  web/admin_api.py      API админ-панели (права проверяются на сервере)
  web/auth.py           проверка initData, сессии админки, подписи ссылок
  web/dist/             собранный фронтенд (создаётся командой сборки)
  handlers/             чат-бот: /start, запись в чате, админка в чате (/admin), /panel
webapp/                 React + TypeScript
  src/pages/            Home, Services, Gallery, Profile
  src/booking/          пошаговая запись и календарь
  src/admin/            админ-панель: Dashboard, Bookings, CalendarAdmin, ServicesAdmin, Masters, Schedule, Clients, GalleryAdmin, SettingsAdmin
  src/components/       дизайн-система: кнопки, чипсы, шторки, фото, лайтбокс, нижняя навигация
  src/services/         api.ts (HTTP-клиент), telegram.ts (SDK), mock.ts (только демо-сборка)
  src/hooks/, src/utils/, src/types.ts
tests/                  pytest: сценарии бота, гонки, API, мастера, права админа
```

## Переменные окружения (`.env`)
| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | токен бота от @BotFather (**секрет**, только в `.env` или настройках хостинга) |
| `ADMIN_IDS` | Telegram ID мастера и администраторов через запятую (узнать: @userinfobot) |
| `WEBAPP_URL` | публичный **HTTPS**-адрес приложения, например `https://nails.example.ru` |
| `TZ_NAME` | часовой пояс студии, например `Europe/Moscow` |
| `PORT` | порт веб-сервера (по умолчанию 8080) |
| `DATA_DIR` | где хранить базу и фото (по умолчанию `./data`, в Docker — `/data`) |

Других ключей не нужно. В коде фронтенда нет ни токенов, ни паролей.

## Запуск

### Локально
```bash
# 1. сервер
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env            # впишите BOT_TOKEN, ADMIN_IDS, WEBAPP_URL

# 2. фронтенд (нужен Node.js 20+)
cd webapp && npm ci && npm run build && cd ..

# 3. старт
python -m app
```
Для HTTPS при локальной проверке подойдёт `cloudflared tunnel --url http://localhost:8080`. Полученный адрес впишите в `WEBAPP_URL`.

### Docker (рекомендуется для сервера)
```bash
cp .env.example .env   # заполните
docker compose up -d --build
```
Фронтенд соберётся внутри образа. База и фото лежат в `./data`: **бэкап — это копия этой папки.**

### Хостинг
- **VPS + домен.** Caddy или nginx перед контейнером, сертификат Let's Encrypt.
- **Railway, Render, Amvera.** Подключите репозиторий: Dockerfile уже готов. Задайте переменные, подключите постоянный диск к `/data` и укажите выданный HTTPS-адрес в `WEBAPP_URL`.

### Настройка в Telegram
1. Бот сам ставит кнопку меню «Запись ♡», которая открывает Mini App (если задан `WEBAPP_URL`).
2. Канал: добавьте бота **администратором канала**, затем в админке → «Настройки» укажите ID канала. Без этого проверка подписки не работает.
3. **Вход в админку:** напишите боту `/panel`. Он пришлёт:
   - кнопку «Открыть в Telegram»: вход по подписи Telegram, права проверяет сервер;
   - одноразовую ссылку для браузера на компьютере: действует 10 минут, затем сессия на 7 дней.

   Посторонний не войдёт: сервер пускает только ID из `ADMIN_IDS`.

## Проверка
```bash
pip install -r requirements-dev.txt && pytest          # 20 тестов сервера
cd webapp && npx tsc -b                                # проверка типов
python scripts/preview_webapp.py 8099 <папка-с-фото>   # локальный предпросмотр с демо-данными
```
Демо-сборка для показа без сервера: `cd webapp && npm run build:demo`. Она использует примеры данных в браузере и в рабочую сборку не попадает.
